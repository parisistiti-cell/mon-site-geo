 Il s'agit d'une application interactive de géolocalisation en Europe avec :

    🗺️ Carte Leaflet interactive centrée sur l'Europe
    🔍 Recherche intelligente de communes, rues et lieux-dits
    🌍 Filtrage par pays (26 pays européens)
    📸 Photos haute qualité depuis Wikimedia (activées pour la France)
    🎨 Design moderne avec interface élégante
